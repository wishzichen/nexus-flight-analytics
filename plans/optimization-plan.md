# 航班延误分析系统 - 数据探索模块优化方案

## 一、当前问题分析

### 1.1 用户体验问题
| 问题 | 现状 | 影响 |
|------|------|------|
| 筛选无反馈 | 选择筛选条件后直接生效，无法取消或确认 | 用户可能误操作 |
| 无搜索功能 | 仅支持下拉筛选，无法搜索特定航班 | 查询效率低 |
| 导出不完整 | 只导出当前页100条数据 | 无法获取完整筛选结果 |

### 1.2 数据流问题
```
当前流程:
用户选择筛选 → 立即触发API请求 → 返回单页数据 → 只能导出当前页

期望流程:
用户选择筛选 → 确认应用 → 显示筛选结果 → 导出筛选后的所有数据
```

## 二、优化方案设计

### 2.1 前端优化 (Module8DataExplorer.tsx)

#### 新增功能：
1. **搜索框**：支持航班号、航司、航线关键词搜索
2. **确认筛选按钮**：筛选后需点击按钮才应用筛选条件
3. **重置按钮**：一键恢复默认筛选条件
4. **筛选状态指示**：显示当前筛选条件和命中记录数
5. **全量导出按钮**：导出筛选后的所有符合条件的数据

#### 界面布局调整：
```
┌─────────────────────────────────────────────────────────────────┐
│  总记录数    平均延误   平均距离   航司数   航线数              │
├─────────────────────────────────────────────────────────────────┤
│  🔍 搜索航班号/航线...  │ [全部航司▼] [全部目的地▼] [延误等级▼] │
│                         │ [重置] [应用筛选]  命中: XX 条       │
├─────────────────────────────────────────────────────────────────┤
│  📋 数据表格                                     [导出CSV↓]     │
│  日期 | 航司 | 航班号 | ...                                      │
│  ─────────────────────────────────────────────────────────────  │
│  ...                           分页: < 1 2 3 ... 100 >          │
├─────────────────────────────────────────────────────────────────┤
│  💡 使用说明                                                    │
└─────────────────────────────────────────────────────────────────┘
```

### 2.2 后端API增强 (server.ts)

#### 新增接口：
```
1. GET /api/module8/search
   - 支持参数: q(搜索词), airline, destination, delayLevel, page, pageSize
   - 返回: 筛选后的分页数据 + 总记录数

2. GET /api/module8/export
   - 支持参数: q, airline, destination, delayLevel, all (boolean)
   - 返回: 完整筛选结果的CSV文件

3. GET /api/module8/filtered-stats
   - 返回: 当前筛选条件下的统计摘要
```

#### 响应结构优化：
```typescript
interface SearchResponse {
  data: Flight[];           // 当前页数据
  total: number;            // 总匹配数
  page: number;             // 当前页
  pageSize: number;         // 每页大小
  filters: {
    q?: string;
    airline?: string;
    destination?: string;
    delayLevel?: string;
  };
}
```

## 三、交互流程优化

### 3.1 筛选流程
```
用户操作:
1. 在搜索框输入关键词 或 选择下拉筛选条件
2. 点击「应用筛选」按钮
3. 系统发送请求到后端
4. 显示加载状态 (spinner)
5. 展示筛选结果和命中数量
6. 用户可点击分页浏览或导出

用户取消:
- 点击「重置」按钮 → 恢复默认状态
```

### 3.2 导出流程
```
用户操作:
1. 设置筛选条件并应用
2. 点击「导出CSV」按钮
3. 如果数据量 ≤ 1000 条：直接下载
4. 如果数据量 > 1000 条：显示确认弹窗
   - 「确定导出全部 X 条数据？」
   - 选择每批导出量
5. 下载CSV文件
```

## 四、数据筛选逻辑

### 4.1 筛选条件
| 字段 | 类型 | 说明 |
|------|------|------|
| q | string | 模糊搜索：航班号、航司名称、航线 |
| airline | string | 航司代码筛选 |
| destination | string | 目的地机场代码 |
| delayLevel | string | 延误等级：准点/轻微/中度/严重 |

### 4.2 优先级
1. 搜索词 (q) 优先匹配航班号
2. 多条件组合为 AND 逻辑
3. 空值视为不筛选
